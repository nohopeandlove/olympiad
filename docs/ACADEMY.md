# Сбой в Академии Алгоритмов

В панели администратора блок «Готовое приключение» создаёт олимпиаду для выбранной аудитории (школьники или СПО), один основной этап и восемь задач. Повторное нажатие открывает существующую копию и сохраняет её изменения. Ранее созданные олимпиады и задачи не заменяются. Космические шаблоны из прежней версии заменены главами Академии.

Сначала олимпиада имеет статус «Черновик». В «Этапах» установите даты, время и длительность (по умолчанию 180 минут). В «Настройках» проверьте сроки регистрации, разрешённые классы и правила. Статус «Запланирована» показывает карточку и позволяет регистрацию в заданный период; «Олимпиада открыта» также разрешает начало этапа в его сроки. Настройки даты и времени в админке используют часовой пояс браузера; публичное расписание показывает время Екатеринбурга.

| Глава | Задача | Точное правило | Публичный пример |
|---|---|---|---|
| 1 | Код от двери | Сумма цифр неотрицательного N; для 0 ответ 0 | `5072` → `14` |
| 2 | Повреждённый пропуск | Второе по величине **различное** число; если его нет, `NO` | `5` / `4 9 9 2 7` → `7` |
| 3 | Сообщение Null | После удаления **ровно одного** символа получается палиндром; пустая строка допустима | `abca` → `YES` |
| 4 | Энергетический тоннель | Максимальное количество элементов непрерывного строго возрастающего участка | `6` / `1 2 2 3 4 1` → `3` |
| 5 | Два ключа | Количество пар индексов i < j с суммой K; одинаковые коды считаются разными ключами | `5 5` / `1 4 2 3 2` → `3` |
| 6 | Лабиринт Академии | Кратчайший путь по четырём направлениям из S в T; стены #; нет пути — `-1` | `1 3` / `S#T` → `-1` |
| 7 | Резервное питание | Минимум батарей 1, 3, 4 для точной суммы N; запас каждого типа неограничен | `6` → `2` |
| 8 | Последний протокол | Соседние узлы в обе стороны и один направленный телепорт из каждого узла; любой переход стоит один шаг | `5` / `3 2 5 4 5` → `2` |

Задачи оцениваются в 100 баллов каждая, всего 800. У каждой — два публичных примера и скрытые проверки, включая границы, повторяющиеся значения, отсутствие решения, большие входы, циклы телепортов. Всего 69 тестов. Звёзды означают возрастающую сложность, а не множитель баллов. Судья сравнивает токены вывода, игнорируя различия в пробелах.

Главы отображаются в сюжетном порядке, но не блокируют друг друга: участник может решать в любом порядке. Прогресс отмечает только официальные решения со статусом Accepted; публичный запуск и частичные баллы не завершают главу. После Accepted на задаче 8 открывается кнопка «Открыть финал приключения». Финал доступен также в личном кабинете после окончания этапа. Сам текст финала отдаёт backend только зарегистрированному участнику, решившему последнюю задачу.

Для добавления отдельных глав используйте «Добавить задание» → «Глава приключения» → «Использовать выбранную главу». Условие, ограничения, лимиты, баллы и тесты можно редактировать до начала этапа участниками.

Источник задач, тестов и финала: `backend/app/content/academy.json`. Связь задания с главой хранится в `tasks.academy_chapter`; обновление схемы выполняет миграция 0002. При обновлении Docker автоматически применяет миграции. Условия требуют стандартного ввода/вывода; графика и дополнительные библиотеки не нужны.

## Обновление локальной установки

Из клона проекта выполните `git pull --ff-only`, затем `docker compose -p olympiad-main up --build -d`. Если исходный Compose-проект назывался иначе, используйте его имя. Обновление включает frontend, backend и worker. После сборки обновите страницу (Ctrl+F5), войдите администратором и нажмите «Создать приключение». Папку проекта, `.env` и том базы данных сохраняйте.

Карта на главной показывает реальные задания выбранного опубликованного этапа, включая дополнительные задачи, а не фиксированный список из шаблона. Выберите олимпиаду и этап над картой. После сохранения изменения видны при возвращении на вкладку главной или её обновлении. Черновики на публичной главной не отображаются.
